System Architecture

How It Works — Real-Time Pipeline

Data flow from client keystrokes through the WebSocket communication layer to the CRDT conflict-resolution engine and persistent database storage.

1. Delta Capture

When a user types or draws, local input is translated into fine-grained Yjs document deltas without blocking the editor UI.

2. WebSocket Stream

Socket.IO streams the encoded delta payload to the active room room channel on Render with sub-50ms latency.

3. CRDT Convergence

Remote peers receive the state update and integrate it mathematically via Lamport vectors, guaranteeing identical convergence.

4. Auto Persistence

Authoritative document snapshots and CRDT binary updates are debounced and persisted reliably into MongoDB Atlas.
