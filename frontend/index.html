CollabSpace Full-Stack Architecture & Local Setup

Complete React + Vite + TypeScript + TipTap + Express + MongoDB + Yjs project is packaged in collabspace-fullstack.zip

# 1. Extract the full-stack project ZIP
unzip collabspace-fullstack.zip && cd collabspace
# 2. Configure environment variables (.env.example provided)
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
# 3. Install dependencies & start MongoDB + Express + Vite
./setup.sh
cd backend && npm run dev
cd frontend && npm run dev
